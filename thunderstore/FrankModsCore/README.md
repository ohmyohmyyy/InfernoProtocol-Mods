# FrankMods Core

Shared settings infrastructure for FrankMods releases.

FrankMods Core adds a **Mod Settings** entry to the pause menu. Installed FrankMods automatically register their supported keyboard and controller shortcuts, so players only see settings for the mods they have installed.

BetterUI is optional. When present, Mod Settings follows its selected color palette; otherwise it uses the standard FrankMods green theme.
