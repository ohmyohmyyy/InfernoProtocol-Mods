# BetterUI

Refined crafting menus and a living DNA tree for your acquired genetics.

## Features

- Clearer recipes, ingredients, categories, and craft-button states.
- Search and live recipe availability updates.
- Integrated fabrication progress.
- Five selectable color palettes that persist between sessions.
- Restores the hand-crafting launcher correctly after closing the menu.
- A compact genetics tree with curved branches, gene icons and native descriptions.
- Mouse/controller navigation, pan, zoom, recentering and optional reduced motion.

Open genetics normally to explore your collection. This is a visual upgrade only: it does not grant genes or change their effects. GeneticsTest is not included.

Use the crafting footer's color-wheel button to change palettes. Press `F8` to pause or resume BetterUI for the current session.

Full setup, configuration, compatibility, and troubleshooting details are available on [GitHub](https://github.com/ohmyohmyyy/InfernoProtocol-Mods#betterui).
