# 0.5.0

- First Renovator release.
- Adds 27 curated surface finishes for compatible walls, floors, ceilings, and roofs.
- Adds post-placement movement and rotation using the game's native placement preview and snapping.
- Supports mouse, keyboard, and controller controls with safe input restoration.
- Replaces the Building Hammer's opaque target wash with a lightweight mint outline on placeable objects.
- Shares generated textures and mapped meshes, batches world restoration, and avoids closed-menu scene scans.
